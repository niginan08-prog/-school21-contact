Цветовая палитра уже обновлена:
- основной фон: #0D1F2E
- акцентный цвет: #B1C90D
- карточки и границы подобраны в тон палитре.

Шрифт Masiva подключен через локальные файлы в папке assets.
Чтобы он отображался у всех пользователей, добавьте в папку assets два файла шрифта, полученные по подходящей лицензии:
- Masiva-Regular.woff2
- Masiva-Bold.woff2

Важно: сами файлы шрифта в архив не включены. Без них страница покажет запасной системный шрифт. Для веб-сайта нужна соответствующая webfont-лицензия. Информация о семействе и вариантах лицензирования: https://graviton.com.ar/masiva

Замените style.css в корне репозитория. Остальные файлы менять не требуется. Затем добавьте файлы шрифта в assets и нажмите Commit changes. После публикации обновите страницу мини-приложения.
