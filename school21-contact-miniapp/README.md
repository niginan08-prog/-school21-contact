# Мини-приложение СШ «Контакт» для MAX

## Что внутри
- `index.html` — главная страница.
- `style.css` — оформление.
- `app.js` — поведение интерфейса и получение имени через MAX Bridge.
- `data.js` — редактируемые телефоны и контакты.
- `assets/` — логотип и фотографии направлений.

## Перед публикацией
1. Откройте `data.js`.
2. Замените `ДОБАВИТЬ НОМЕР` на реальные телефоны.
3. Добавьте адрес, электронную почту и ссылку ВКонтакте.
4. Сохраните изменения.

Телефоны в карточках направлений становятся нажимаемыми ссылками, если указать номер с кодом страны, например `+7...`.

## Публикация через GitHub Pages
1. Загрузите все файлы и папку `assets` в корень репозитория.
2. В GitHub откройте Settings → Pages.
3. В разделе Build and deployment выберите Deploy from a branch.
4. Выберите ветку `main` и папку `/ (root)`, нажмите Save.
5. Дождитесь публикации. GitHub покажет HTTPS-адрес сайта в этом же разделе.

## Подключение к MAX
В платформе MAX для партнёров откройте Чат-боты → выберите бота → ⋮ → Настройки.
Вставьте HTTPS-адрес опубликованного сайта в поле ссылки на мини-приложение, выберите кнопку запуска и сохраните.

## Важно
Имя пользователя читается из `window.WebApp.initDataUnsafe.user.first_name` через официальную библиотеку MAX Bridge. В обычном браузере приветствие останется без имени.
